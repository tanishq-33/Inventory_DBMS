# Vite React Tailwind App

This project is a React application set up with Vite and styled using Tailwind CSS. It serves as a template for building modern web applications with a fast development experience.

## Features

- Fast development with Vite
- Styled with Tailwind CSS
- Modular structure with components and pages
- Example API utility functions

## Getting Started

To get started with this project, follow the instructions below.

### Prerequisites

Make sure you have the following installed:

- Node.js (version 14 or higher)
- npm (comes with Node.js)

### Installation

1. Clone the repository:

   ```
   git clone <repository-url>
   ```

2. Navigate to the project directory:

   ```
   cd vite-react-tailwind-app
   ```

3. Install the dependencies:

   ```
   npm install
   ```

### Running the Application

To start the development server, run:

```
npm run dev
```

This will start the application and you can view it in your browser at `http://localhost:3000`.

### Building for Production

To build the application for production, run:

```
npm run build
```

The built files will be output to the `dist` directory.

### Customizing Tailwind CSS

You can customize the Tailwind CSS configuration in the `tailwind.config.cjs` file. Add any custom styles or themes as needed.
